# Dataset cards

| Card | Data folder | Kind | Used in the paper for |
|---|---|---|---|
| [jshc.md](jshc.md) | `data/jshc/` | simulated, generated by us (protocol of prior work) | prediction (Table 1, Fig. 1b, 3, 6, 7), queries without a change (Table 2), models of the control task |
| [escphc.md](escphc.md) | `data/escphc/` | simulated, generated by us (protocol of prior work) | prediction (Table 1, Fig. 3, 6, 7), queries without a change (Table 2) |
| [escphc_beyond.md](escphc_beyond.md) | `data/escphc_beyond/` | simulated, generated by us | changes beyond the training range (Table 2) |

| [ur5e.md](ur5e.md) | `data/ur5e/` | simulated, built by us | prediction (Table 1, Fig. 1b, 3, 6, 7), robot-arm examples (Fig. 4), queries without a change (Table 2) |
| [hopper.md](hopper.md) | `data/hopper/` | simulated, built by us | prediction (Table 1, Fig. 1b, 3, 6, 7), queries without a change (Table 2) |
| [alfa.md](alfa.md) | `data/alfa/` | sequences derived from real recorded flights (ALFA) | prediction on real flights (Table 2) |
| [control_episodes.md](control_episodes.md) | `data/control_episodes/` | simulated start conditions, generated by us | control task (Table 2) |

All sequences have 301 states and 300 transitions at dt = 0.05 s. A query uses a 64-step context and the 40 following actions and states; queries start at steps 64, 96, 128, 160 and 192 of every test sequence (5 queries per sequence). Models read only `obs` and `act`; every other array is an analysis label and is never given to any model. The splits are TRAIN, VAL, TEST and TEST_B (the paper's TE-B); the paper uses TEST and TEST_B together as the test set.

Commands (run from the repository root unless stated otherwise):

- Check the files: `sha256sum -c datasets/SHA256SUMS`, and array by array: `python datasets/check_data.py --data data`.
- Regenerate: `bash datasets/regenerate_all.sh OUT_DIR [dataset ...]` (see the cards for the environments; the script ends with the check against `datasets/ARRAY_SHA256.json` and `datasets/SHA256SUMS`). In our runs every regenerated file was byte-identical with the pinned packages on Linux x86-64; on a CPU with AVX-512 this was shown only with AVX-512 switched off in NumPy (`NPY_DISABLE_CPU_FEATURES`, `OPENBLAS_CORETYPE=Haswell`). On other systems `datasets/check_data.py` compares the arrays.
- Panda and UR5e need the MuJoCo Menagerie models: `bash datasets/assets/fetch_menagerie.sh`.
- ALFA needs the original archive: `bash datasets/alfa/download_alfa.sh`.
- Analysis labels of the test queries (change phases, queries without a change, queries with transient disturbances, queries beyond the training range): `python datasets/labels.py --data-root data --out OUT_DIR`.
