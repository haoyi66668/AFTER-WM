# Control episodes: start conditions of the JSHC control task

48 test episodes for the control task of the paper (Table 2; supplement Sec. C.5, "Control task"), generated by us with `datasets/control_episodes.py` (it uses the JSHC generator, the shared core `datasets/simcore/` and the plant and constants of `control/`).

## Content

- Every episode has T = 304 control steps of 0.05 s on Gymnasium 1.3.0 `HalfCheetah-v5`: steps 0-63 are an open-loop warm-up with the JSHC start-state and action-plan rules (the 64 actions at the start of the plan of the episode), which fills the 64-step context of the world models; steps 64-303 are the 240 MPC steps.
- Joint without power: j0 for steps < 104 (MPC steps < 40), j1 for 104-203, j2 from step 204 (MPC step 140) on; j0 is uniform over the five leg joints bshin, bfoot, fthigh, fshin, ffoot (action indices 1-5), j1 and j2 are uniform over the four joints other than the current one, so every switch is a real change.
- The episodes use their own seed namespace and are disjoint from the JSHC data.

## Arrays

| key | dtype, shape | meaning |
|---|---|---|
| `warm_act` | float32 [48, 64, 6] | warm-up actions (commanded, before the power of the joint is removed) |
| `warm_obs` | float32 [48, 65, 17] | states of the warm-up, from the start state to step 64 |
| `fail` | int8 [48, 304] | joint without power at every control step |
| `meta_json` | str [] | JSON: schema, seed namespace, split, seed offset 21, counts, step constants, package versions and the per-episode start-state and joint records |

## Generation

Environment as for JSHC. From `datasets/`, with the repository root on `PYTHONPATH` (for `control/`): `python -B -m control_episodes --split test --n 48 --out OUT/control_episodes/episodes_test_v1.npz` (also run by `bash datasets/regenerate_all.sh OUT control_episodes`).
Seeds are derived from a fixed namespace string (`NS` in `control/spec.py`) and the position of the draw.
The namespace string is a fixed identifier (`docs/FIXED_IDENTIFIERS.md`); changing it changes every random draw.
